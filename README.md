# 美容の道具箱｜セラピスト目線の美容案内

美容案件専門の静的サイト（GitHub Pages想定）。Felis cattus のサイトとは無関係の独立サイトです。
生成：`python3 build.py` で全HTMLを再生成します。

## 状態（MVP）
- 全ページの商品・案件枠はプレースホルダ（「案件準備中（ASP登録後に掲載）」）。実在の商品名・価格は未掲載
- `build.py` の `BASE` は仮置き。公開先のGitHubアカウントが決まったら実URLに差し替えて再生成すること

## 公開後の手順
1. リポジトリ作成 → Pages公開
2. A8.net の既存アカウントにこのサイトをメディア追加、afb に新規メディア登録
3. 案件選定 → リンク発行 → `build.py` の slot 枠へ実リンク（rel="sponsored nofollow noopener"）を差し込んで再生成
4. 楽天アフィリエイトを使う場合は、サイトURLの登録を済ませてからリンクを貼る
5. Google Search Console に登録し、sitemap.xml を送信

## 法令ガードレール
- 広告リンクのあるページは冒頭にPR表記（ステマ規制対応）
- 化粧品・健康食品に効能効果を謳わない（薬機法配慮）。サプリは食品として案内し作用を断定しない
- ランキングは比較条件を明示し、二重価格表示をしない（景表法配慮）
